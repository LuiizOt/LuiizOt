### Portfólio de Ciência de Dados
---
Estudos de caso completos desenvolvidos no programa de Ciência de Dados da TripleTen. Cada repositório documenta o problema, a metodologia, os resultados verificados e as limitações (documentação em inglês).

| Projeto | Problema abordado | Principais resultados |
|---|---|---|
| [Movie Review Sentiment Analysis](https://github.com/LuiizOt/movie-review-sentiment-analysis) | Detectar automaticamente críticas negativas do IMDB (NLP) | F1 de teste **0,88**, ROC-AUC **0,95** |
| [Used Car Price Prediction](https://github.com/LuiizOt/used-car-price-prediction) | Estimar o valor de mercado de carros usados, equilibrando precisão e velocidade | LightGBM RMSE **2.108**, R² **0,78** |
| [Insurance ML and Data Masking](https://github.com/LuiizOt/insurance-ml-data-masking) | Encontrar clientes semelhantes, prever benefícios e proteger dados pessoais | kNN F1 **0,97**; métricas inalteradas após o mascaramento |
| [Oil Well Region Profit and Risk Analysis](https://github.com/LuiizOt/oil-well-region-profit-risk-analysis) | Escolher a região de petróleo mais lucrativa com restrição de risco | Lucro médio **USD 4,56 mi**, risco de prejuízo **1,5%** |
| [Bank Customer Churn Prediction](https://github.com/LuiizOt/bank-customer-churn-prediction) | Prever quais clientes vão deixar o banco | F1 de validação **0,62**, ROC-AUC **0,85** |
| [Telecom Plan Recommendation](https://github.com/LuiizOt/telecom-plan-recommendation-classification) | Recomendar o melhor plano de celular a partir do uso | Acurácia de validação **0,802** |
| [Chicago Taxi Rides Analysis](https://github.com/LuiizOt/chicago-taxi-rides-analysis) | Demanda de táxis e efeito do clima nas corridas ao aeroporto | Efeito do clima significativo (α = 0,05) |
| [Telecom Plan Revenue Analysis](https://github.com/LuiizOt/telecom-plan-revenue-analysis) | Identificar qual plano pré-pago gera mais receita | Receita difere por plano (p ≈ 2,9 × 10⁻¹⁴) |
| [Instacart Shopping Behavior Analysis](https://github.com/LuiizOt/instacart-shopping-behavior-analysis) *(em andamento)* | Comportamento de compra e recompra em supermercado | Visão geral de ≈ 5 milhões de linhas |

**Stack:** Python · pandas · NumPy · scikit-learn · LightGBM · SciPy · Matplotlib · seaborn · NLTK · spaCy · Jupyter
