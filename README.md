## About me

Cartographic and Surveying Engineer (UFPR) and GIS/LiDAR team lead, moving into geospatial data science. I turn point clouds and spatial data into decisions for public infrastructure, using Python and machine learning.

- 🛰️ **Day to day:** LiDAR point clouds (registration, cleaning, terrain models), ArcGIS Enterprise on-premises, BIM/IFC publishing and a managing a team.
- 🎓 **Training:** TripleTen's Data Scientist program (about 630 hours, 2025 to 2026).
- 🔭 **Here:** case studies in machine learning and statistics, plus Flamelit, an interactive map of wildfire hotspots in Paraná built with GeoPandas and Folium. Work data, imagery and code are not published here.
- 🌎 Curitiba, Brazil (UTC-3), open to remote collaboration.

### Data Science Portfolio
---
End-to-end case studies developed during the TripleTen Data Science program. Each repository documents the problem, methodology, verified results and limitations.

| Project | Problem addressed | Key results |
|---|---|---|
| [Telecom Customer Churn Prediction](https://github.com/LuiizOt/telecom-customer-churn-prediction) *(final project)* | Predict which telecom customers will cancel their contracts | Tuned LightGBM F1 **0.73**, ROC-AUC **0.91** |
| [Movie Review Sentiment Analysis](https://github.com/LuiizOt/movie-review-sentiment-analysis) | Automatically detect negative IMDB movie reviews (NLP) | Test F1 **0.88**, ROC-AUC **0.95** |
| [Used Car Price Prediction](https://github.com/LuiizOt/used-car-price-prediction) | Estimate used-car market value, balancing accuracy and speed | LightGBM RMSE **2,108**, R² **0.78** |
| [Insurance ML and Data Masking](https://github.com/LuiizOt/insurance-ml-data-masking) | Find similar customers, predict benefits and protect personal data | kNN F1 **0.97**; metrics unchanged after masking |
| [Oil Well Region Profit and Risk Analysis](https://github.com/LuiizOt/oil-well-region-profit-risk-analysis) | Choose the most profitable oil region under a risk constraint | Mean profit **USD 4.56 M**, risk of loss **1.5%** |
| [Bank Customer Churn Prediction](https://github.com/LuiizOt/bank-customer-churn-prediction) | Predict which customers will leave the bank | Validation F1 **0.62**, ROC-AUC **0.85** |
| [Telecom Plan Recommendation](https://github.com/LuiizOt/telecom-plan-recommendation-classification) | Recommend the best mobile plan from usage behavior | Validation accuracy **0.802** |
| [Chicago Taxi Rides Analysis](https://github.com/LuiizOt/chicago-taxi-rides-analysis) | Taxi demand and the effect of weather on airport trips | Weather effect significant (α = 0.05) |
| [Telecom Plan Revenue Analysis](https://github.com/LuiizOt/telecom-plan-revenue-analysis) | Identify which prepaid plan generates more revenue | Revenue differs by plan (p ≈ 2.9 × 10⁻¹⁴) |
| [Instacart Shopping Behavior Analysis](https://github.com/LuiizOt/instacart-shopping-behavior-analysis) *(in progress)* | Grocery ordering and reordering behavior | Data overview of ≈ 5 million rows |

**Stack:** Python · pandas · NumPy · scikit-learn · LightGBM · SciPy · Matplotlib · seaborn · NLTK · spaCy · Jupyter
